## 読み方

国別の入口で在留資格と保険を確認し、検索して必要な章を開きます。保存は自分のブラウザ内だけで行います。ダウンロードした `index.html` を開けば本文をオフラインで読めます。出典の閲覧は通信が必要です。GitHubで長い本文の表示が省略される場合は閲覧ページかダウンロードをご利用ください。
